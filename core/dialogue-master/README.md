# dialogue-master

Dialogues aux standards de l'édition française : guillemets, tirets demi
cadratin, incises, attribution par l'action, conflit d'objectifs, sous-texte,
différenciation des voix, multilinguisme.

- Entrées : fiches personnages, fiche de scène.
- Sorties : dialogues conformes, rapport de voix.
- Dépendances : writing-constitution.
- Contrôle : proofreader, literary-editor.
