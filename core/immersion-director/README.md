# immersion-director

Immersion culturelle et sensorielle : lieux, cultures, langues, climats,
paysages, traditions, gastronomie, sons, odeurs. Dosage par type de scène et
contrôle anti-exotisme.

- Entrées : bible du monde, dossier documentaire, fiche de scène.
- Sorties : dossier sensoriel par lieu, passages immersifs.
- Dépendances : writing-constitution, world-builder, research-director.
