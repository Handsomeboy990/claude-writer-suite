# narrator

Gestion de l'instance narrative : personne, focalisation, temps, distance,
discours indirect libre, contrat de connaissance, narrateur non fiable, voix.

- Entrées : bible du roman, choix de point de vue.
- Sorties : charte de narration, page témoin de voix.
- Dépendances : writing-constitution.
- Contrôle : continuity-manager, literary-editor.
