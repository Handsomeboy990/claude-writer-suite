# hackathons

Finding, planning, and winning a hackathon. Three skills, governed by
[../ideation/opportunity-core](../ideation/opportunity-core/).

| Skill | Purpose |
|---|---|
| [hackathon-discovery](hackathon-discovery/) | find real events matched to the participant; verify eligibility and deadlines against the source |
| [hackathon-strategy](hackathon-strategy/) | read the rubric, scope a project to finish, plan a working demo early, protect the submission |
| [pitch-and-demo](pitch-and-demo/) | a problem-first pitch and a working demo, honest and rehearsed |

A hackathon is a real event with real deadlines and eligibility rules, verified
against the source. The scoping principle wins more hackathons than any idea:
finish something whole and small, then make it better.
