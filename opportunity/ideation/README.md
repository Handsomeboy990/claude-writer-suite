# ideation

Generating and choosing ideas, for any domain. Three skills: the constitution,
the divergent generator, and the convergent evaluator.

| Skill | Purpose |
|---|---|
| [opportunity-core](opportunity-core/) | constitution: discover, evaluate, recommend; grounding rule; binding constraint |
| [ideation-engine](ideation-engine/) | generate a diverse, grounded set worth evaluating, not a long list of variations |
| [idea-evaluation](idea-evaluation/) | converge to a ranked few; find each survivor's riskiest assumption and its cheap test |

Start at `opportunity-core`. It is the constitution of the whole opportunity tree,
depends on nothing, and can be used alone.
