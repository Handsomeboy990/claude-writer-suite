# career-core

Constitution of the career tree. A job listing, company fact, deadline or salary
is never invented and always traced to a live source; a CV and cover letter
state nothing the candidate cannot support; the tree reads its configuration
before acting; and the candidate's real profile is kept distinct from an
aspirational one.

- Inputs: the candidate's real situation, via the career configuration.
- Outputs: career config, honesty standard, source rule, candidate profile.
- Depends on: nothing. Copy the directory and use it alone.
- Downstream: every career skill refers to it and none restates it.

Two rules never bend: nothing about the outside world is invented (a listing is
traced to a live source or withheld), and nothing about the candidate is claimed
that they cannot support in a conversation. The strongest application is a true
one, presented well.
