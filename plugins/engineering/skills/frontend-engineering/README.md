# frontend-engineering

Client side implementation to production standard: convention reading, the
five required UI states, a state placement decision order, data fetching
rules, form quality, a non negotiable accessibility list, responsive rules,
rendering performance, purposeful animation and internationalisation.

- Inputs: design decisions, project conventions, the API contract.
- Outputs: components, client state, UI states, accessibility notes.
- Depends on: engineering-core, project-exploration, ui-ux-engineering.
- Downstream: testing-quality, playwright-automation,
  performance-engineering, code-review-protocol.

A view that implements only the success path is unfinished. Loading, empty,
error and partial are part of the feature, not follow up work.
