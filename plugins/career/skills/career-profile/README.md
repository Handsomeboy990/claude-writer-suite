# career-profile

Builds the candidate's foundational profile that every other career skill reads:
the real skill inventory with honest levels, the experience history with
quantified results, the target roles and their real requirements, the strengths
and genuine gaps, and the narrative that ties a non-linear history together.

- Inputs: the candidate's real history and the career configuration.
- Outputs: skill inventory, experience history, target definition, career narrative.
- Depends on: career-core.
- Downstream: cv-engineering, job-search, cover-letter, interview-preparation.

The source of truth a CV, a search and an interview all draw from, so they do not
each invent their own version of the candidate. A result with a true number beats
any adjective. A genuine career pivot is a strength when it is owned, not a
straight line to disguise.
