# Career profile template

The structure the other career skills read. Fill it from the candidate's real
history and the career configuration. Every entry is supportable in a conversation.

## Skill inventory
```
For each skill:
  name        the skill
  level       independent | with support | learning | aware of
  evidence    the experience that proves it (required for any "independent")
Grouped by: technical, domain, interpersonal, tools.
```

## Experience history
```
For each role:
  title       the real title held
  org         the organisation
  dates       accurate, including gaps
  scope       size and stakes, so a reader gauges the level
  results     quantified where honest numbers exist; accurate action verbs
              (led / built / coordinated / supported / contributed)
```

## Target definition
```
target_roles        from the configuration
requirements        the real requirements of those roles, from actual listings
map                 for each requirement: met | partly | gap
```

## Strengths and gaps
```
strengths           requirements met strongly -> what the CV and search lead with
transferable        a strength from one domain covering another's requirement,
                    made explicit
gaps                requirements not met, named honestly
close_paths         for each gap: a project, a course, or an honest "stretch, and
                    why it is still worth trying"
```

## Narrative
```
through_line        the real thread across the history
pivots              any genuine change of direction, owned as a pivot
addressed           any gap in dates or short tenure, briefly and honestly explained
```

## The test
A recruiter reads the profile and can, for every claim, imagine the interview
question that probes it and the honest answer that satisfies it. If any claim has
no such answer, it is above what the candidate can support, and it is corrected.
