# Match analysis

How to judge and report the fit between a candidate and a real opening, honestly,
so the candidate spends limited application effort well.

## The three verdicts per requirement

```
met       the candidate clearly satisfies it, with evidence in the profile
partly    the candidate has adjacent or lesser experience; a real but incomplete fit
gap       the candidate does not satisfy it
```

Run every requirement in the listing through these three. The pattern across them
gives the overall verdict.

## The overall verdict

```
strong match    most requirements met, none critical in gap
good match      met on the essentials, partly on some secondary ones
stretch         a critical requirement is partly or gap; viable only with a strong
                angle, and labelled as a stretch
poor fit        multiple critical gaps; not worth a real application, said plainly
```

## Reporting the verdict

- Name the specific requirement behind each partly and gap. "Partly on cross-team
  leadership" is useful; "70% match" is not.
- For a stretch, state what would make it viable: which evidence to lead with,
  what gap to acknowledge, whether it is worth the effort.
- For a poor fit, say so. Telling a candidate a role is a poor fit saves them an
  application they would spend on a better one. Career-core forbids flattering a
  candidate into a wasted application.

## What match analysis is not

- Not a score to maximise. A high number on a role the candidate does not want,
  or is not authorised for, is noise.
- Not a reason to hide a gap. The gap is named so the CV, cover letter and
  interview prep can address it, not so it disappears.
- Not the listing's self-description accepted whole. If a listing's "requirements"
  are a wish list (as most are), distinguish the true essentials from the
  nice-to-haves, and match against the essentials.

## The effort principle
Ten strong, tailored applications beat fifty scattered ones. Match analysis
exists to find those ten and to tell the candidate honestly where the other forty
would be wasted.
