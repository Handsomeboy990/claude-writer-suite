# cover-letter

Writes a cover letter that earns the interview: opens with a real reason for this
company and role, connects the candidate's genuine experience to the role's
actual needs with specifics, owns a gap honestly when one is visible, matches the
industry's register, and stays short.

- Inputs: the profile, the role, company-research for the real reason and register.
- Outputs: cover letter, opening hook, evidence connections, gap handling.
- Depends on: career-core, career-profile.
- Downstream: interview-preparation; with cv-engineering forms the application package.

A cover letter that could be sent to any company is read by none. Its whole value
is specificity: this candidate, this company, this role, this reason. A letter
whose company name could be find-and-replaced has failed.
