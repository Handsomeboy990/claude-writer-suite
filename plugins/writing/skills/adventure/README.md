# adventure

Adventure novel: the itinerary as structure, accounting for resources and
attrition, demonstrated competence, a constraining territory, the rhythm of
travel and halt, the mandatory return.

- Inputs: goal, territory, research dossier.
- Outputs: itinerary, adventure outline.
- Depends on: `writing-constitution`, `scene-builder`, `immersion-director`.
- Neighbours: `historical-fiction`, `fantasy`.

## When to use

A journey, an expedition, a survival narrative.

## What creates the tension

Attrition. Strict accounts of food, water, money, health and days remaining,
where what is consumed does not restore itself without a scene. A bag that
always contains what is needed removes the genre's only engine.

## Configuration

`language.creative_output` sets the output language.
