# rewriting-engine

Methodical rewriting: the correct-or-rewrite decision, six modes (function,
point of view, contraction, expansion, register, deletion), an eight-step
protocol, salvage rules, and the signs of a failed rewrite.

- Inputs: an existing text, and a diagnosis.
- Outputs: rewritten version, rewrite log.
- Depends on: `writing-constitution`, `self-critique-protocol`.
- Downstream: `literary-editor`, `proofreader`.

## When to use

When correction is no longer enough: the scene objective is wrong, the voice
is unstable, or three self-critique cycles failed to reach the threshold.

## The rule that makes it work

Never rewrite while looking at the old version. Write from the sheet, then
compare, then salvage only what is genuinely better and does not drag the new
text back to the old rhythm.

## Configuration

`language.creative_output` sets the output language.
