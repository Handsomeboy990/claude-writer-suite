# character-psychologist

Character construction: the seven field core, access layers, behavioural
translation, voice, transformation arcs, relational mapping.

- Inputs: novel bible, social and research context.
- Outputs: character sheets, arcs, relational map.
- Depends on: `writing-constitution`.
- Lateral: `dialogue-master`, `scene-builder`.

## When to use

To build a protagonist, make an antagonist credible, or repair a character
who is flat or inconsistent.

## The idea it rests on

A character is a system of tensions, not a list of traits. The seven field
core of section 2 is enough to write any scene they appear in, and section 4
turns each field into something observable, which is the only material a
novelist can actually put on the page.

## Configuration

`language.creative_output` sets the output language.
