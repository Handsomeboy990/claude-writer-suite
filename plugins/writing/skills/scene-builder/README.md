# scene-builder

Scene construction: objective, escalating conflict, costly outcome, reaction,
dilemma, decision. Spatial anchoring, subtext, internal rhythm,
irreversibility.

- Inputs: chapter sheet, character sheets.
- Outputs: written scenes, scene sheets.
- Depends on: `writing-constitution`, `chapter-architect`.
- Lateral: `dialogue-master`, `immersion-director`, `narrator`.

## When to use

To write a scene, repair a flat one, or verify that a scene changes the state
of the narrative.

## Configuration

`language.creative_output` sets the output language.
