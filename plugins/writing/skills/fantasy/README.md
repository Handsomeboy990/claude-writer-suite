# fantasy

Demanding fantasy: the necessity test for the fantastic, magic regimes, the
doubled quest structure, non-monolithic peoples, economy of wonder, prohibited
cliches.

- Inputs: world bible, premise.
- Outputs: fantasy bible, quest plan.
- Depends on: `writing-constitution`, `world-builder`, `novel-architect`.
- Neighbours: `dark-fantasy`, `adventure`, `magical-realism`.

## When to use

A fantasy novel, a magic system, or a secondary world.

## The test that decides the project

Remove the fantastic element. If the narrative still stands, the fantasy is
decorative. The impossible must cause the conflict, not decorate it, and
section 2 asks that before anything is built.

## Configuration

`language.creative_output` sets the output language.
