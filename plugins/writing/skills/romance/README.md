# romance

Romance built on the internal obstacle: seven stages of intimacy, tension
through thwarted desire, intimate scenes with consequences, subgenre
contracts, prohibited cliches.

- Inputs: both character sheets, the target subgenre.
- Outputs: relationship arc, outline.
- Depends on: `writing-constitution`, `character-psychologist`,
  `scene-builder`.
- Neighbours: `historical-fiction`, `adventure`.

## When to use

A love story, a romantic comedy, a slow burn.

## What it refuses

The prolonged misunderstanding that one sentence would dispel. The obstacle is
internal: each character carries a lie, and the other makes it untenable.
Everything external is a revealer, not a cause.

## Configuration

`language.creative_output` sets the output language.
