# Checklist thriller

## Fondations
- [ ] Enjeu vital énoncé avant la fin du chapitre 3.
- [ ] Échéance matérielle identifiée.
- [ ] Antagoniste avec compétence supérieure démontrée.
- [ ] Coût de chaque tentative défini.

## Structure
- [ ] Longueur des chapitres décroissante vers le climax.
- [ ] Moins d'un cliffhanger par trois chapitres.
- [ ] Point médian recadrant le problème.
- [ ] Aucune information nouvelle dans le dernier tiers.

## Tension
- [ ] Échéance rappelée par un fait toutes les vingt pages.
- [ ] Au moins une réalisation partielle de la menace.
- [ ] Issues fermées une à une, jamais rouvertes.
- [ ] Respirations placées après les pics.

## Crédibilité
- [ ] Procédures documentées au niveau 2 minimum.
- [ ] Aucune facilité technologique.
- [ ] Aucun sauvetage par hasard.
- [ ] Les autorités agissent de façon plausible.

## Interdits
- [ ] Aucun monologue explicatif du méchant.
- [ ] Aucun retournement qui annule le récit.
- [ ] Aucune menace familiale employée comme seul moteur.
