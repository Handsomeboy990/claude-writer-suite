# timeline-manager

Time management: master chronology against reader chronology, markers,
ellipses, flashbacks in italic, multi-line narratives, felt duration.

- Inputs: master outline, bible, written chapters.
- Outputs: master chronology, reader chronology, flashback table.
- Depends on: `writing-constitution`, `novel-architect`.
- Lateral: `chapter-architect`, `continuity-manager`.

## When to use

To place a flashback, check dates, or clarify a chronology the reader can no
longer follow.

## The distinction it exists for

Two chronologies, kept as separate documents: the real order of events, and
the order in which the reader learns them. The gap between them is suspense
and surprise. Skills that keep only one end up producing that gap by accident.

## Configuration

`language.creative_output` sets the output language.
