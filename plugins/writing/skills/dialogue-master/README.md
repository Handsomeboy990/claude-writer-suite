# dialogue-master

Dialogue to French publishing standards: guillemets, en dashes, incises,
attribution by action, conflict of objectives, subtext, voice differentiation,
multilingual handling.

- Inputs: character sheets, scene sheet.
- Outputs: conformant dialogue, voice report.
- Depends on: `writing-constitution`.
- Review: `proofreader`, `literary-editor`.

## When to use

To write dialogue, correct its typography, or when every character speaks
alike.

## Output language

Sections 1 and 2 are French typographic conventions and are replaced when
`language.creative_output` is set to another language. Sections 3, 4 and 6,
the dramatic construction and the voice differentiation, apply in any
language.

## Resources

`resources/regles-typographiques-dialogue.md` is French reference data, kept
in French because it is the material the skill produces.
