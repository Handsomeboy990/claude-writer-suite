# mystery

Mystery construction: the two accounts, fairness rules, clue typology and
concealment, honest false trails, the structure of the revelation.

- Inputs: premise, the complete chronological account of the facts.
- Outputs: mystery plan, clue table.
- Depends on: `writing-constitution`, `novel-architect`, `timeline-manager`.
- Neighbours: `detective`, `thriller`.

## When to use

A puzzle, a whodunit, or any narrative built toward a final reveal.

## The rule that governs everything

Write the account of what happened first, in full, and never publish it. The
account of the discovery is written second, from the first. Any mystery
drafted in reading order produces clues that were placed to be found rather
than to be missed.

## Configuration

`language.creative_output` sets the output language.
