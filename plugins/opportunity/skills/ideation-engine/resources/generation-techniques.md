# Idea generation techniques

Deliberate techniques that force range, so the set differs in kind and not in
wording. Apply several; each surfaces ideas the others miss.

## Vary the axes
- Mechanism: different ways the same outcome is achieved.
- Audience: different sub-groups within the problem's audience.
- Business model: different ways it sustains itself.
- Ambition: the deliberately minimal version and the deliberately ambitious one.
- Time: the version for now, and the version for a changed near future.

## Include the extremes
- The smallest thing that could possibly help (often the right first step).
- The most ambitious version (reveals the ceiling and the real vision).
- The answer is frequently between them, and neither endpoint is seen without
  generating both.

## Invert the default
- Generate the approach that does the opposite of the obvious one: flip who the
  user is, flip what is automated, flip what is paid for. Inversion surfaces the
  assumptions the default hides.

## Combine and constrain
- Combine two unrelated approaches and see if the hybrid is stronger than either.
- Add a hard constraint (no budget, one weekend, no marketing) and generate only
  what survives it; the constraint often produces the most shippable idea.

## Ground as you go
- For each idea, state the specific real need it rests on, and mark whether that
  need is observed or assumed. An idea with no nameable need is a solution looking
  for a problem, and it is set aside or reframed.

## The range test, not the count test
Stop when the set spans the axes, not when it hits a number. Then collapse the
near-duplicates: if two ideas differ only in wording, they are one idea, and the
set is smaller and more honest for saying so. Range is the metric; volume is not.
