# Building an outreach angle

An outreach angle is the specific, true, current reason this message makes sense
to this person now. It is what separates a message that gets read from a template
that gets deleted. Built from sourced research, never from a hook.

## The three ingredients

```
1  the real reason now
   the specific, current, true reason to reach out: a signal from discovery,
   deepened. A recent event, a stated goal, a public problem, an open role. It is
   current (a signal has a shelf life) and it is true (a recipient knows their own
   situation and spots an invented one instantly).

2  the connection to real value
   how the provider's offering genuinely answers that reason. Not a manufactured
   link, but a real one: the offering solves the pain the signal reveals. If the
   reason and the offering do not genuinely connect, this is the wrong prospect or
   the wrong angle.

3  the honest, light ask
   a low-friction next step (a short call, a look, a specific question), framed
   around the value, not around the provider's need for the sale. Honest about
   what the provider offers; an angle that oversells sets up a failure at the
   first meeting.
```

## The test for an angle

Read the opening line. Could it be sent, unchanged, to a different company? If yes,
it is a template, not an angle, and it is rebuilt around a sourced specific about
this prospect. The angle that names the recipient's own recent post, open role, or
stated problem passes; "companies like yours" fails.

## Grounding and consent

- Every specific in the angle is from a live source. Never an invented event,
  quote, or detail; a personalised message built on a wrong fact is worse than a
  generic one.
- Public professional information only. Research informs the angle; it never
  crosses into a personal detail that reads as surveillance.
- The angle is drafted and handed over. It is not sent on the provider's behalf
  without explicit per-message confirmation.

## Timing
A fresh signal makes an angle welcome; a stale one makes it noise. Approaching a
company the week after the event the angle references is a different reception from
approaching them six months later. Note the signal's recency, and prioritise the
prospects whose reason-to-reach-out is current.
