# idea-evaluation

Converges a set of ideas to a ranked, defensible few: pressure-tests each
premise against reality, scores on feasibility, value, fit, cost and risk for the
real actor, identifies each survivor's riskiest assumption and the cheapest way
to test it, and recommends with reasoning and next steps.

- Inputs: a generated idea set from ideation-engine, the actor and criteria.
- Outputs: evaluation matrix, ranked ideas, riskiest assumptions, validation plan.
- Depends on: opportunity-core.
- Downstream: project-brief, delivery-orchestrator, hackathon-strategy.

The convergent half of ideation. Killing a doomed idea in evaluation is worth
more than building it and learning the same thing in six months. The output is
not "build this"; it is the most promising idea plus the cheapest way to find out
if it is real before committing.
