# research-core

Constitution of the research tree. The question stated before the search, the
source hierarchy that ranks a primary document above a summary, the rule that a
source is cited only if it was actually consulted, the separation of fact from
inference from opinion, and the honest report of what could not be established.

- Inputs: a question and the decision it serves.
- Outputs: research question, source hierarchy, evidence standard, uncertainty record.
- Depends on: nothing. Copy the directory and use it alone.
- Downstream: every research skill refers to it and none restates it.

General-purpose research, distinct from writing/research-director, which serves
fiction. Two rules never bend: a source is never cited unless it was actually
consulted, and a gap is stated honestly rather than filled with a plausible
invention.
