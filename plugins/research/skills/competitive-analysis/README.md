# competitive-analysis

Analyses a comparative landscape from verifiable evidence: defines the axes that
matter to the decision before seeing the options, gathers each option's real
characteristics from primary sources, compares like-for-like, separates observed
fact from marketing claim, and states the trade-offs rather than crowning a
winner.

- Inputs: the options, the decision the comparison serves.
- Outputs: comparison axes, evidence matrix, trade-off analysis, recommendation.
- Depends on: research-core, source-research.
- Downstream: synthesis-reporting, report-writing, technology-selection.

Axes chosen after seeing the options tend to be the axes the preferred option
wins. The point of the analysis is the trade-off, not the score. An option's own
comparison page is never a source about a competitor.
