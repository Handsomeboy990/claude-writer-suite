# rewriting-engine

Réécriture méthodique : décision corriger ou réécrire, six modes (fonction,
point de vue, contraction, expansion, registre, suppression), protocole en
huit étapes, règles de récupération, signes d'une réécriture ratée.

- Entrées : texte existant, diagnostic.
- Sorties : version réécrite, journal de réécriture.
- Dépendances : writing-constitution, self-critique-protocol.
