# publication-review

Final validation: seven checks (conformity, continuity, promises, research,
representation, correction, book apparatus), technical file checks, a written
decision, and the publication dossier.

- Inputs: the final manuscript and every upstream report.
- Outputs: validation report, publication decision.
- Depends on: `writing-constitution`, `continuity-manager`, `proofreader`.

## When to use

At the very end, after editing, proofreading and the continuity audit.

## When not to use

To judge literary quality. That is `literary-critic`, and it runs before this.

## What it changes

Nothing. It validates or returns with a closed list. The decision is written
and dated: no verbal decision, no implicit approval.

## The dossier

The seven items in section 5 are the memory of the book. They serve the next
volume, an adaptation, and any editorial dispute. Delivering the manuscript
without them delivers half the work.

## Configuration

`language.creative_output` sets the output language.
