# Checklist de publication

Projet :
Date :
Responsable :

## Contrôle 1, conformité constitution
- [ ] Grille de conformité complète passée, zéro manquement.

## Contrôle 2, continuité
- [ ] Audit en huit passages fourni.
- [ ] Zéro incohérence bloquante.
- [ ] Zéro incohérence majeure.
- [ ] Incohérences mineures listées et acceptées.

## Contrôle 3, promesses
- [ ] Toutes les promesses ouvertes tenues.
- [ ] Reports vers un tome suivant consignés.

## Contrôle 4, documentation
- [ ] Chaque affirmation de niveau 3 adossée à une fiche.
- [ ] Checklist anachronismes passée.

## Contrôle 5, représentation
- [ ] Profil de lecture concerné consulté.
- [ ] Aucun décor exotique, aucune caricature.
- [ ] Sujets sensibles traités avec leurs conséquences.

## Contrôle 6, correction
- [ ] Relevé de corrections clos.
- [ ] Cas douteux tranchés par l'auteur.

## Contrôle 7, appareil du livre
- [ ] Titre définitif.
- [ ] Titres de chapitre validés et non génériques.
- [ ] Table des matières cohérente.
- [ ] Exergue, dédicace, remerciements, mentions légales.

## Contrôles techniques
- [ ] UTF-8.
- [ ] Aucun double espace.
- [ ] Aucune espace en fin de ligne.
- [ ] Numérotation continue.
- [ ] Styles homogènes.

## Décision
- [ ] Validé
- [ ] Validé sous réserve
- [ ] Renvoyé
- [ ] Suspendu
