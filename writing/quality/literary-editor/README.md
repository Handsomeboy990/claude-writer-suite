# literary-editor

Édition stylistique en six passes : paragraphe, verbes, adverbes et adjectifs,
rythme, images, conformité. Table des corrections fréquentes, note éditoriale,
journal des coupes, limites d'intervention.

- Entrées : texte révisé.
- Sorties : texte édité, note éditoriale, journal des coupes.
- Dépendances : writing-constitution, self-critique-protocol.
- Aval : proofreader, publication-review.
