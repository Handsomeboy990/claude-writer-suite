# poet

Skill général de poésie : prosodie française (mètres, césure, rimes,
enjambement), travail de l'image et du son, procédure de composition en sept
étapes, interdits, seuils de qualité relevés.

- Entrées : noyau, contrainte, forme visée.
- Sorties : poèmes, note prosodique.
- Dépendances : writing-constitution.
- Aval : sonnet, haiku, free-verse, prose-poetry.
