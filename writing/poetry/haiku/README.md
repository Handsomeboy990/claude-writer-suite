# haiku

Haiku en français : compte souple, marqueur de saison local, technique de la
coupure et de l'écart entre images, interdits (aphorisme, métaphore,
sentiment formulé), composition en séries.

- Entrées : perception concrète, saison, lieu.
- Sorties : haikus, série saisonnière.
- Dépendances : writing-constitution, poet.
