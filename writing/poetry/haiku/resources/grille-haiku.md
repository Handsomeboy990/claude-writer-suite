# Grille de contrôle du haiku

| Élément | Contrôle |
|---|---|
| Compte | 13 à 17 syllabes, déséquilibre maîtrisé |
| Marqueur de saison | concret, local, vérifiable |
| Coupure | franche, entre deux images |
| Type d'écart | échelle, temps, sensoriel, humain et non humain, présence et absence |
| Verbes | présent ou absence de verbe |
| Adjectifs évaluatifs | aucun |
| Comparaison | aucune |
| Je explicite | absent, sauf nécessité |
| Titre | aucun |

## Banque de marqueurs saisonniers non européens
- Saison sèche : poussière sur les feuilles, marché de bois, puits bas.
- Début des pluies : première boue, toits qui résonnent, termites ailées.
- Pleines pluies : rivière brune, ponts coupés, moisissure.
- Fin des pluies : herbe haute, moustiques, récolte du manioc.
