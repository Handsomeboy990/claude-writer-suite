# examples

A complete demonstration project, used as a reference by the documentation and
by the internal examples of the writing skills.

- `saga-les-cendres-de-kivu/`: the first volume of a five-volume saga,
  documented from the bible through to the validation report.

The project is in French, since it demonstrates what the writing tree
produces.

It is fictional. The institutions and procedures appearing in it are plausible
and researched, but none corresponds to a real organisation.
