# timeline-manager

Gestion du temps : chronologie maîtresse et chronologie lecteur, repères,
ellipses, flashbacks en italique, récits à lignes multiples, durée ressentie.

- Entrées : plan général, bible, chapitres rédigés.
- Sorties : chronologie maîtresse, chronologie lecteur, table des flashbacks.
- Dépendances : writing-constitution, novel-architect.
- Latéral : chapter-architect, continuity-manager.
