# Table de traduction comportementale

Aucune émotion ne se nomme. Elle se déduit.

| État intérieur | Signes utilisables | À éviter |
|---|---|---|
| Angoisse | vérifie l'heure sans la lire, range ce qui est déjà rangé | coeur qui bat la chamade |
| Colère contenue | parle plus bas, articule, ne coupe pas | mâchoire serrée, poings serrés |
| Chagrin ancien | continue un geste devenu inutile, garde un couvert | larmes le long des joues |
| Honte | choisit une place d'où l'on voit la sortie, paye d'avance | rougit violemment |
| Mensonge | ajoute un détail non demandé, répond trop vite | regard fuyant |
| Épuisement | fait deux choses à moitié, s'assoit sur le bord | soupire longuement |
| Désir | remarque un détail précis et inutile chez l'autre | papillons dans le ventre |
| Peur physique | perception rétrécie, sons trop nets, temps ralenti | sang qui se glace |
| Soulagement | s'aperçoit qu'il a faim | souffle qu'il retenait |
| Jalousie | devient généreux de façon excessive | vert de jalousie |

Règle d'usage : un signe par occurrence, jamais trois accumulés. La précision
d'un seul détail vaut mieux que l'accumulation.
