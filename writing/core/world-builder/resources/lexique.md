# Lexique du monde

Ne créer que les mots employés dans le texte. Maximum quinze entrées pour un
roman, trente pour une saga.

| Terme | Sens | Première apparition | Introduit par | Traduction interdite |
|---|---|---|---|---|
|  |  | ch. | contexte, usage, objet |  |

Règles :
- Aucun terme n'est glosé entre parenthèses.
- Un terme est compris au plus tard à sa deuxième occurrence.
- Cohérence phonétique : un même monde ne mélange pas des sonorités issues de
  familles trop éloignées sans justification historique interne.
- Les pluriels et dérivés sont fixés dès la création.
