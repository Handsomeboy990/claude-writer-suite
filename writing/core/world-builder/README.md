# world-builder

Construction d'univers cohérents : contrainte matérielle, géographie,
économie, pouvoir, croyances, technique, langue, systèmes spéciaux,
révélation par l'usage.

- Entrées : genre, dossier documentaire, besoins dramatiques.
- Sorties : bible du monde, règles internes, cartographie, lexique.
- Dépendances : writing-constitution, research-director.
- Latéral : immersion-director, timeline-manager.
