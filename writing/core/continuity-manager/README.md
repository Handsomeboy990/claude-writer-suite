# continuity-manager

Mémoire externe du projet : huit registres (personnages, savoir, objets,
lieux, temps, corps, règles, langue), protocole de mise à jour par chapitre,
audit complet en huit passages, classement des incohérences.

- Entrées : chapitres rédigés, bibles, plan.
- Sorties : registre de continuité, rapport d'incohérences.
- Dépendances : writing-constitution.
- Aval : publication-review.
