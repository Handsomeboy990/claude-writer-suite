# continuity-manager

External memory of the project: eight registers (characters, knowledge,
objects, places, time, bodies, rules, language), a per-chapter update
protocol, an eight-pass full audit, and a severity ranking for
inconsistencies.

- Inputs: written chapters, bibles, outline.
- Outputs: continuity register, inconsistency report.
- Depends on: `writing-constitution`.
- Downstream: `publication-review`.

## When to use

Continuously, after every chapter. And in full before any delivery.

## Why it is not optional

Inconsistency past a hundred thousand words is mechanical, not careless. The
knowledge register in section 2.2 is the one that earns its keep: most serious
inconsistencies come from a character using information they cannot hold.

## Threshold

No axis below 4, against 3 elsewhere in this tree. Continuity does not accept
an average.

## Configuration

`language.creative_output` sets the output language.
