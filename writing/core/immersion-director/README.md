# immersion-director

Cultural and sensory immersion: places, cultures, languages, climates,
landscapes, traditions, food, sounds, smells. Dosage by scene type and an
anti-exoticism check.

- Inputs: world bible, research dossier, scene sheet.
- Outputs: sensory dossier per place, immersive passages.
- Depends on: `writing-constitution`, `world-builder`, `research-director`.
- Review: `literary-editor`, `beta-reader`.

## When to use

To make a place live, or when a description reads like a tourist brochure.

## The check that matters

Section 5, anti-exoticism. Four questions, and a single unfavourable answer
requires a rewrite. It is the operational form of section 8 of the
constitution: a culture is represented with the same detail and dignity as the
reader's own, or it is scenery.

## Configuration

`language.creative_output` sets the output language.
