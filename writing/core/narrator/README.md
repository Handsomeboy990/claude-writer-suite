# narrator

Management of the narrating instance: person, focalisation, tense, distance,
free indirect speech, knowledge contract, unreliable narrator, voice.

- Inputs: novel bible, point of view choice.
- Outputs: narration charter, reference page for the voice.
- Depends on: `writing-constitution`.
- Review: `continuity-manager`, `literary-editor`.

## When to use

To choose a point of view, correct a focalisation slip, or stabilise a voice
across a long manuscript.

## Note on the examples

Sections 3 and 8 use French examples, because narrative distance and free
indirect speech are demonstrated in the language they are written in. The
five-degree model applies in any output language.

## Configuration

`language.creative_output` sets the output language.
