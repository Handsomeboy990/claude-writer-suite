# scene-builder

Construction de scènes : objectif, conflit en escalade, issue coûteuse,
réaction, dilemme, décision. Ancrage spatial, sous-texte, rythme interne,
irréversibilité.

- Entrées : fiche chapitre, fiches personnages.
- Sorties : scènes rédigées, fiches de scène.
- Dépendances : writing-constitution, chapter-architect.
- Latéral : dialogue-master, immersion-director, narrator.
