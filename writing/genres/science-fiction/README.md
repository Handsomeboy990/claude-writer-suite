# science-fiction

Science-fiction rigoureuse : formulation du novum, méthode des quatre niveaux
de conséquences, exigences par sous-genre, règles d'infrastructure et de
panne, exposition sans didactisme.

- Entrées : hypothèse de départ, dossier documentaire.
- Sorties : novum formulé, bible technologique, plan.
- Dépendances : writing-constitution, world-builder, research-director.
