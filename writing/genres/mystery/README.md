# mystery

Construction du mystère : les deux récits, règles d'équité, typologie et
dissimulation des indices, fausses pistes honnêtes, structure de la
révélation.

- Entrées : prémisse, récit chronologique complet des faits.
- Sorties : plan du mystère, table des indices.
- Dépendances : writing-constitution, novel-architect, timeline-manager.
