# dystopian

Dystopie crédible : loi du fonctionnement, quatre leviers de contrôle dont
l'intime, langue du pouvoir, personnage lucide qui paye sa lucidité, fins
possibles, interdiction de la thèse énoncée.

- Entrées : système, bénéfice réel, population.
- Sorties : système de contrôle documenté, plan.
- Dépendances : writing-constitution, science-fiction, world-builder.
