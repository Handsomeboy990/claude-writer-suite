# magical-realism

Magical realism: the rule of non-astonishment, social and material anchoring,
ordinary phrasing of the extraordinary, practical consequences, a
storyteller's voice, meaning left open.

- Inputs: realist base, marvellous motif, social context.
- Outputs: marvellous charter, outline.
- Depends on: `writing-constitution`, `immersion-director`, `narrator`.
- Neighbours: `fantasy`, `prose-poetry`.

## When to use

A narrative where the marvellous is a commonplace fact rather than an
intrusion.

## The test that separates it from fantasy

If a character asks how this is possible, the text has tipped into the
fantastic. Nobody is astonished; they deal with who cleans up, who pays, and
what the neighbours say.

## Configuration

`language.creative_output` sets the output language.
