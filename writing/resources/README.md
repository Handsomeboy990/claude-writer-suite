# resources

Material shared by every writing skill. Any skill may refer to these files;
none may duplicate their content.

These files are French reference data. They are what the skills produce rather
than how they are instructed, which is why they keep their French names and
their French content while the skills themselves are written in English.

| File | Contents |
|---|---|
| `typographie-francaise.md` | the typographic standard applied across the tree |
| `structures/structures-narratives.md` | catalogue of usable narrative structures |
| `lexiques/verbes-de-parole.md` | speech verbs: permitted, tolerated, prohibited |
| `lexiques/mots-a-bannir.md` | worn formulas, intensifiers, cliches |
| `lexiques/vocabulaire-sensoriel.md` | a bank of concrete perceptions |
| `templates/demarrage-de-projet.md` | project opening questionnaire |
| `templates/journal-de-projet.md` | production and quality log |

When `language.creative_output` is set to a language other than French, the
typography file and the lexicons no longer apply. The affected skills say so
and require the target language's own conventions rather than approximating
from these.
