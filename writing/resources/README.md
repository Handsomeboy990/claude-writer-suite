# resources

Ressources partagées par l'ensemble des skills. Tout skill peut y renvoyer,
aucun ne doit en dupliquer le contenu.

- `typographie-francaise.md` : norme typographique appliquée à toute la suite.
- `structures/structures-narratives.md` : catalogue des structures utilisables.
- `lexiques/verbes-de-parole.md` : verbes autorisés, tolérés, proscrits.
- `lexiques/mots-a-bannir.md` : formules usées, intensifieurs, clichés.
- `lexiques/vocabulaire-sensoriel.md` : banque de perceptions concrètes.
- `templates/demarrage-de-projet.md` : questionnaire d'ouverture de projet.
- `templates/journal-de-projet.md` : suivi de production et de qualité.
