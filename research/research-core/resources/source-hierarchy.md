# The source hierarchy

Rank every source before trusting it. Prefer the top of the ladder; use lower
rungs for orientation, never as the final word on a claim that matters.

## The ladder

```
1  primary        the thing itself
                  a law: the enacted text in the official journal
                  a scientific claim: the peer-reviewed paper, its methods and data
                  a company fact: the filing, the official release, the API docs
                  a code behaviour: the source code and its tests
                  a dataset claim: the dataset itself

2  official        the responsible body's own statement
                  the vendor's documentation, the agency's guidance, the
                  maintainer's changelog, the standards body's specification

3  reputable        independent reporting or analysis that cites its own sources
                  and can be followed back to a primary

4  aggregated       a summary, an encyclopedia entry, a listicle, an AI answer
                  useful to orient and to find primaries; never the citation itself

5  unattributed     a claim with no source: a forum post, an unsourced statistic,
                  a rumour; a lead to verify, never evidence
```

## Rules for using the ladder

- A claim that matters is followed to rung 1 or 2. Stopping at rung 4 for a
  decision-critical fact is how errors propagate.
- An aggregator that cites a primary is a route to the primary, not a substitute.
  Follow the citation and read the primary.
- Recency matters within a rung: an official statement from last year may be
  superseded by one from last week. Check the date.
- Conflict of interest matters: a vendor's benchmark of its own product is
  official but interested. Note the interest.
- A lower rung can raise a question the higher rungs must answer, but it cannot
  settle it.

## The consulted rule, restated

A source at any rung is cited only if it was actually opened and read. The ladder
ranks sources by reliability; it does not license citing a primary you did not
consult because it is high on the ladder. Consulted first, ranked second.
