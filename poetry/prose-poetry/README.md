# prose-poetry

Poème en prose : bloc compact, quatre forces de cohésion (rythme, champ
lexical, progression sensorielle, clôture), familles de formes, procédure en
sept étapes, pièges du lyrisme et de la chute explicative.

- Entrées : lieu, instant ou objet unique.
- Sorties : proses poétiques.
- Dépendances : writing-constitution, poet.
