# Catalogue des structures narratives

## Trois actes
Installation, confrontation, résolution. Points de bascule à 12, 25, 50, 75 et
90 pour cent. Usage : intrigue orientée objectif. Risque : milieu mou.

## Quatre parties
Deux moitiés d'acte central séparées par le point médian. Usage : thriller,
mystère, récit à échéance. Risque : mécanique visible.

## Kishotenketsu
Introduction, développement, twist, conclusion. Le twist n'est pas un conflit
mais un déplacement de perspective. Usage : récit contemplatif, littérature
blanche, nouvelle. Risque : absence de tension pour un lecteur de genre.

## Structure en spirale
Retour cyclique des mêmes lieux, motifs ou situations, chaque retour modifiant
le sens du précédent. Usage : saga, roman de mémoire. Risque : répétition
perçue si le sens ne se déplace pas.

## Récit enchâssé
Un récit contient un autre récit, avec un narrateur intermédiaire. Usage :
transmission, enquête intime, témoignage. Risque : perte du fil principal.

## Chronologie éclatée
Ordre de lecture différent de l'ordre réel. Usage : trauma, révélation
différée. Risque : confusion. Exigence : marqueur constant par ligne
temporelle.

## Récit choral
Plusieurs points de vue de poids équivalent, convergeant. Usage : fresque
sociale, catastrophe. Risque : dispersion, attachement faible.

## Structure par unité de lieu
Le lieu impose la contrainte et la durée. Usage : huis clos, récit de siège.
Risque : épuisement des situations.

## Structure documentaire
Alternance de récit et de documents, rapports, lettres, procès-verbaux.
Usage : enquête, roman politique. Risque : rupture d'immersion si les
documents ne sont pas des scènes.

## Tableau de sélection

| Objectif principal | Structure recommandée |
|---|---|
| Tenir un lecteur en haleine | quatre parties |
| Explorer une conscience | trois actes ou récit enchâssé |
| Peindre une société | choral ou documentaire |
| Travailler la mémoire | spirale ou chronologie éclatée |
| Écrire une saga | spirale, avec question de saga |
| Écrire court | kishotenketsu |
