# detective

Roman d'enquête : choix de l'école, construction de l'enquêteur, progression
en neuf étapes, vérité de métier, technique de l'interrogatoire, clichés à
proscrire.

- Entrées : table des indices, dossier documentaire du milieu.
- Sorties : dossier d'enquête, procédure.
- Dépendances : writing-constitution, mystery, character-psychologist.
