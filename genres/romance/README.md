# romance

Romance construite sur l'obstacle interne : sept paliers d'intimité, tension
par désir contrarié, scènes d'intimité conséquentes, contrats de sous-genre,
clichés à proscrire.

- Entrées : fiches des deux personnages, sous-genre visé.
- Sorties : arc relationnel, plan.
- Dépendances : writing-constitution, character-psychologist, scene-builder.
