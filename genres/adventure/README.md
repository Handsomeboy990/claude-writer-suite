# adventure

Roman d'aventure : itinéraire comme structure, comptabilité des ressources et
attrition, compétence démontrée, territoire contraignant, rythme
déplacement et halte, retour obligatoire.

- Entrées : but, territoire, dossier documentaire.
- Sorties : itinéraire, plan d'aventure.
- Dépendances : writing-constitution, scene-builder, immersion-director.
