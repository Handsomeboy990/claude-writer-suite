# thriller

Écriture de thriller : enjeu vital, échéance visible, antagoniste compétent,
coût croissant. Mécaniques de tension, rythme des chapitres, clichés à
proscrire, exigence de crédibilité procédurale.

- Entrées : prémisse, plan général, dossier documentaire.
- Sorties : plan thriller, scènes de tension.
- Dépendances : writing-constitution, novel-architect, scene-builder.
