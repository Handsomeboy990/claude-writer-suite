# publication-review

Validation finale : sept contrôles (conformité, continuité, promesses,
documentation, représentation, correction, appareil du livre), contrôles
techniques de fichier, décision écrite, dossier de publication.

- Entrées : manuscrit final et tous les rapports amont.
- Sorties : rapport de validation, décision de publication.
- Dépendances : writing-constitution, continuity-manager, proofreader.
