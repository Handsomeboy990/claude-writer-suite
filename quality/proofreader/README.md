# proofreader

Correction orthographique, grammaticale et typographique en cinq passes
spécialisées. Typographie française, pièges du français romanesque,
homogénéité, relevé de corrections. Aucune intervention stylistique.

- Entrées : texte édité.
- Sorties : texte corrigé, relevé de corrections.
- Dépendances : writing-constitution.
- Aval : publication-review.
